# Weather App

## Overview
The Weather App provides users with current weather information and forecasts based on their location. It aims to deliver accurate and timely data in an easy-to-use interface.

## Features
- Current weather data with temperature, humidity, and wind speed.
- Weather forecasts for the next 7 days.
- Location-based services to provide results based on user location.
- Easy-to-use interface with responsive design.

## Technologies Used
- **Frontend:** tinker
- **Backend:** python
- **APIs:** OpenWeatherMap API for weather data.

## Setup and Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/MphoJr/Weather_app.git
   ```
2. Navigate into the project directory:
   ```bash
   cd Weather_app
   ```
3. Install the dependencies:
   ```bash
   pip install
   ```
   
4. Start the application:
   ```bash
   python Weather_app.py
   ```

## Usage
After starting the application, open your browser and navigate  to view the Weather App. You can enter your location to get weather updates.
